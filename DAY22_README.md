# Bluestock — Day 22 Streamlit App Scaffold

## Files
- `src/dashboard/app.py`
- `src/dashboard/utils/db.py`
- `src/dashboard/pages/01_home.py` through `08_reports.py`

## Install
```powershell
pip install streamlit pandas
```

## Run from the project root
```powershell
streamlit run src/dashboard/app.py
```

The scaffold uses the existing database at:
`data/nifty100.db`

Day 22 focuses on the application scaffold and shared cached database access. The remaining screen functionality is implemented in Days 23–25.
